# Peminjaman Lab - Frontend

Frontend aplikasi peminjaman laboratorium menggunakan Next.js.

## Teknologi

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Moment.js

## Instalasi

```bash
npm install
```

## Menjalankan Development Server

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Build untuk Production

```bash
npm run build
npm start
```
