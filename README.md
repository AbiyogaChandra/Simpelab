# Simpelab

## Setup

1. Clone repository ini.

```bash
git clone https://github.com/Abiyoga Chandra/projek-ukk.git
```

2. Masuk ke dalam folder projek ini.

```bash
cd projek-ukk
```

3. Download dependencies.

```bash
npm install
```

4. Generate Prisma Client.

```bash
npx prisma generate
```

5. Buat file database.

```bash
npx prisma db push
```

6. Start server.

```bash
npm run dev
# atau
yarn dev
# atau
pnpm dev
# atau
bun dev
```

7. Kunjungi [http://localhost:3000](http://localhost:3000) untuk melihat websitenya.
